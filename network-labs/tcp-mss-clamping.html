💡 Architectural Insight: MSS Clamping is a Ceiling, Not a Floor

A router running an ip tcp adjust-mss policy evaluates transit handshakes conditionally. It can only decrease an MSS field size if the client's request surpasses the threshold bounds. If a host initiates a small payload that passes safely below the limit, the router takes zero action and lets it traverse the link completely unchanged.
